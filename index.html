What is Dancing Grandpa?

Dancing Grandpa is a delightful baby entertainment system built with the Bevy game engine in Rust. It features animated dancing characters synchronized to music, designed to captivate and entertain babies and toddlers.

Features:

  • Multiple animated dancing grandpa characters
  • Tempo-synchronized animations
  • Configurable number of dancers and music tempo
  • Automatic restart loop with fade effects
  • Available as both desktop and web applications
